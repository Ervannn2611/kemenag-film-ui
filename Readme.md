# 🎬 Kemenag: Film Platform

A modern, responsive, and immersive streaming platform frontend inspired by Kemenag's (Ministry of Religious Affairs of the Republic of Indonesia) vision to provide high-quality and inspirational films.

This project was developed based on the specified UI/UX guidelines, utilizing a dark mode aesthetic and the Poppins typeface for a premium cinematic experience.

---

## ✨ Features

* **Dark Mode Native Design:** Premium, immersive cinematic aesthetic using a dark palette with gold/orange (`#f59e0b`) accents.
* **Fully Responsive:** Optimized layout for desktop, tablet, and mobile devices (using Tailwind CSS).
* **Structured Pages:** Complete set of necessary pages for a streaming service.
* **Interactive UI:** Hover effects on film thumbnails, dedicated search functionality, and a dedicated user account dashboard.
* **Indonesian Language:** All textual content is localized in Indonesian.
* **Legal Compliance:** Includes pages for Privacy Policy, Terms & Conditions, and other legal documents.

---

## 🛠️ Technology Stack

* **Frontend Framework:** Pure HTML5
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **Typography:** [Poppins Font](https://fonts.google.com/specimen/Poppins)
* **Icons:** [Material Symbols Outlined](https://fonts.google.com/icons)

## 🚀 Getting Started

To run this project locally, clone the repository and open the HTML files in your web browser. Since all styling is handled via the Tailwind CDN link within the HTML files, no local build process is required.

1.  **Clone the repository:**
    ```bash
    git clone [Your Repository URL]
    ```

2.  **Navigate to the project directory:**
    ```bash
    cd [Your Project Folder Name]
    ```

3.  **Open the files:**
    Open `index.html` (for the homepage) or any other `.html` file directly in your preferred web browser.
